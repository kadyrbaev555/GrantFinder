# Задачи frontend для MVP GrantFinder

Стартовая страница уже проверяет соединение с API через `GET /health`. Следующий этап — дать студентам Казахстана возможность найти подходящую программу, проверить условия участия и перейти к официальному источнику. Маршруты для списка и деталей программ запланированы в [задачах backend](backend-mvp.md).

| Задача | Описание и критерий готовности |
| --- | --- |
| 1. Вывести каталог на главной странице | Подключить каталог к `GET /api/v1/scholarships`. Для каждой из 6–10 проверенных программ показать название, организатора, страну, уровень образования и срок подачи. Если дата отсутствует, вывести «Срок не указан». |
| 2. Добавить поиск и фильтры | Искать по части названия без учёта регистра. Дать пользователю выбрать страну, уровень образования и тип финансирования. При поиске с двумя активными фильтрами все карточки соответствуют запросу и обоим фильтрам. Сброс возвращает полный список. |
| 3. Создать страницу программы | По нажатию на карточку открывать отдельную страницу с данными из `GET /api/v1/scholarships/:id`. Показать описание, требования и условия финансирования. Страница открывается по прямой ссылке, а кнопка «Официальный сайт» ведёт к программе на сайте организатора. |
| 4. Обработать загрузку, пустую выдачу и ошибки | Во время запроса показывать индикатор загрузки. Если совпадений нет, предложить сбросить условия поиска. При ошибке соединения дать повторить запрос. Для программы с ответом 404 показать сообщение и ссылку на каталог. |
| 5. Проверить основной сценарий MVP | В мобильном и настольном браузерах найти программу по названию и двум фильтрам, открыть карточку и перейти на официальный сайт. Отдельно проверить пустую выдачу, программу без срока подачи и открытие страницы по прямой ссылке. |

## Результаты сквозной проверки

21 ноября 2026 года проверена production-сборка коммита `e035165` с Go API и чистой PostgreSQL после применения миграций. Проверка пройдена в Microsoft Edge при размере окна 1440 × 900 и с эмуляцией Pixel 7 (412 × 839).

| Действие | Результат на обоих экранах |
| --- | --- |
| Ввести `dAaD`, выбрать Германию и магистратуру | Из девяти карточек осталась DAAD Scholarships. В карточке и деталях отображается «Срок не указан». |
| Открыть карточку и нажать «Официальный сайт» | Браузер перешёл на страницу базы стипендий DAAD Central Asia и получил HTTP 200 после перенаправления. |
| Открыть `/?program=3` в новой вкладке и обновить страницу | В обоих случаях открылись детали DAAD Scholarships. |
| Ввести `НетТакойПрограммы` и сбросить условия | Появилось сообщение об отсутствии совпадений. Сброс вернул девять карточек. |
| Однократно подменить ответ на поиск DAAD ошибкой HTTP 503 и нажать «Повторить запрос» | Появилось сообщение об ошибке. Повторный запрос к API вернул карточку DAAD. |
| Открыть `/?program=999999` и нажать «В каталог» | API вернул HTTP 404. Страница показала «Программа не найдена», ссылка вернула в каталог. |
