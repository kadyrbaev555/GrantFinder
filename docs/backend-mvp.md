# Задачи backend для MVP GrantFinder

Целевая аудитория — студенты Казахстана, которые ищут бакалаврские, магистерские и международные образовательные программы. Сценарий MVP — найти программу в каталоге, изучить условия и перейти на официальный сайт организатора.

| Задача | Описание и критерий готовности |
| --- | --- |
| 1. Наполнить каталог проверенными программами | Подобрать 6–10 возможностей, доступных целевой аудитории. Сверить требования, финансирование и сроки по официальным ссылкам. Согласовать значения страны, уровня образования и типа финансирования для фильтров. Добавить программы версионированной миграцией данных. На чистой базе появляются все карточки, повторный запуск миграций не создаёт копий. Если дата не опубликована, хранить `NULL`. |
| 2. Реализовать выдачу карточек каталога | Добавить `GET /api/v1/scholarships` и выборку через sqlx. Возвращать ID, название, организатора, страну, уровень образования, тип финансирования и дату подачи. Зафиксировать порядок сортировки и формат пустого списка. |
| 3. Добавить поиск и комбинируемые фильтры | Расширить выдачу поиском по части названия без учёта регистра и фильтрами по стране, уровню образования и типу финансирования. Использовать параметры SQL. При сочетании условий каждая карточка должна удовлетворять всем заданным критериям. |
| 4. Реализовать страницу программы на уровне API | Добавить `GET /api/v1/scholarships/:id`. Вернуть поля карточки, полное описание, требования, условия финансирования и официальный URL. Для некорректного ID вернуть 400, для отсутствующей программы — 404. |
| 5. Проверить сценарий iOS и описать API | На новой базе проверить выдачу, поиск с двумя фильтрами, пустой результат, программу без даты и переход из карточки к деталям и официальному источнику. Зафиксировать в README параметры, примеры JSON и коды ошибок для iOS. Проверить доступность репозитория и инструкции запуска перед публичной сдачей MVP. |
