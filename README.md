# GrantFinder

Открытый каталог стипендий, грантов и образовательных программ для студентов Казахстана. Условия, требования, тип финансирования и ссылка на официальный сайт — на одной странице, с поиском и фильтрами.

Проект сделан командой из трёх студентов KBTU в рамках курса Introduction to Open Source (2026) и распространяется по лицензии [MIT](LICENSE).

## О проекте

### Проблема

Информация о стипендиях разбросана по сайтам вузов, фондов, посольств, государственных порталов и Telegram-каналов. Чтобы найти подходящую программу, студенту приходится открывать десятки страниц, вручную сравнивать требования и проверять, не закрыт ли уже приём. Часть сведений устаревает, часть пересказывается без ссылки на источник. Студенты из регионов, у которых нет знакомых с опытом поступления за рубеж или денег на консультантов, часто просто не узнают о программах вовремя.

### Решение

GrantFinder собирает основные программы в один каталог. По каждой программе видно, кто её проводит, в какой стране учёба, для какого уровня образования, что покрывается и какие требования. Поиск и фильтры помогают за минуту сузить список до подходящих вариантов.

Мы не принимаем заявки и не заменяем официальные сайты. Каждая карточка ведёт на страницу организатора, где студент проверяет актуальные сроки и подаёт документы. Проект бесплатный, без регистрации и рекламы, а код и данные открыты.

## Для кого

- **Студенты и выпускники вузов Казахстана**, которые ищут финансирование для магистратуры, докторантуры или стажировки.
- **Школьники и абитуриенты**, которые рассматривают бакалавриат за рубежом или гранты Nazarbayev University.
- **Карьерные центры и кураторы вузов**, которым нужен готовый список программ, чтобы делиться им со студентами.
- **Разработчики и волонтёры**, которые хотят дополнять каталог или развернуть его для своего вуза или страны.

## Возможности

- **Каталог программ** на главной странице: карточки с названием, организатором, страной, уровнем образования и сроком подачи.
- **Поиск по названию** и **фильтры** по стране, уровню образования и типу финансирования. Фильтры можно сочетать и сбросить одной кнопкой.
- **Страница программы**: описание, требования, условия финансирования и кнопка перехода на официальный сайт.
- **Понятные состояния**: загрузка, «ничего не найдено», ошибка сети с кнопкой повтора.
- Адаптивная вёрстка для компьютера и телефона.
- 9 проверенных программ: Болашак, Fulbright, DAAD, Erasmus Mundus, Chevening, MEXT, Stipendium Hungaricum, гранты Nazarbayev University и Global Korea Scholarship.

## Быстрый старт

Понадобятся Docker Engine с Compose (для backend) и Node.js 22.12+ или 20.19+ с npm (для frontend).

```bash
git clone https://github.com/kadyrbaev555/GrantFinder.git
cd GrantFinder
make
```

`make` поднимает PostgreSQL, применяет миграции, запускает Go API в фоне и затем Vite в текущем терминале. Откройте адрес из вывода Vite, обычно `http://localhost:5173`.

| Команда | Что делает |
| --- | --- |
| `make` или `make up` | backend в фоне, затем frontend в текущем терминале |
| `make backend` | только PostgreSQL, миграции и API на `http://localhost:8080` |
| `make frontend` | только Vite; зависимости ставятся при первом запуске |
| `make down` | останавливает сервисы Compose, данные PostgreSQL сохраняются в томе |

Чтобы остановить frontend, нажмите Ctrl+C в его терминале.

### Настройки

При первом запуске Make создаёт `.env` из [.env.example](.env.example). Пользователь, пароль и имя базы задаются через `PGUSER`, `PGPASSWORD` и `PGDATABASE`, порт API — через `API_PORT`. Файл `.env` не попадает в репозиторий.

### Запуск без Make

Backend (PowerShell, из корня репозитория):

```powershell
Copy-Item .env.example .env
docker compose up --build -d
Invoke-RestMethod http://localhost:8080/health
```

Ответ `{"status":"ok"}` означает, что API подключился к базе. Frontend в отдельном терминале:

```powershell
cd frontend
npm ci
npm run dev
```

В режиме разработки Vite проксирует `/health` и `/api` в backend на порт `API_PORT`. Для production-сборки выполните `npm run build` в каталоге `frontend` — готовые файлы появятся в `frontend/dist/`. Веб-сервер при публикации должен передавать запросы к `/health` и `/api/*` в backend с сохранением пути и параметров.

### База данных

Миграции лежат в `backend/migrations`: первая создаёт таблицу `scholarships`, вторая заполняет каталог. Для новой миграции добавьте файл со следующим номером и секциями `-- +goose Up` и `-- +goose Down`, затем пересоберите образ и проверьте состояние:

```powershell
docker compose up --build -d
docker compose run --rm migrate /app/migrate status
```

## Как пользоваться

1. Откройте главную страницу и нажмите «Смотреть программы» или прокрутите до каталога.
2. Введите часть названия в поиск, например `DAAD`, или выберите страну, уровень образования и тип финансирования.
3. Откройте карточку, чтобы прочитать описание, требования и условия финансирования.
4. Нажмите «Официальный сайт» и проверьте актуальные сроки у организатора. Если срок не указан, значит, у программы нет единой даты или она ещё не объявлена.

Данные каталога можно получать и напрямую через API:

```bash
curl "http://localhost:8080/api/v1/scholarships?q=daad"
curl http://localhost:8080/api/v1/scholarships/3
```

Все параметры, форматы ответов и коды ошибок описаны в [docs/API.md](docs/API.md).

## Откуда данные

Список программ собран вручную. Каждую программу мы проверяли на официальном сайте организатора, посольства или министерства, а не по пересказам в агрегаторах и соцсетях. Описания написаны своими словами.

- [`docs/scholarships.json`](docs/scholarships.json) — исходный список программ по итогам исследования, в открытом формате JSON.
- [`backend/migrations/00002_fill_in_the_catalog.sql`](backend/migrations/00002_fill_in_the_catalog.sql) — версия данных, которая загружается в базу. Последняя проверка — 21 ноября 2026 года.

Если у программы несколько треков со своими датами или новый набор ещё не объявлен, поле `deadline` остаётся пустым (`null`), а в интерфейсе показывается «Срок не указан».

> Условия и сроки программ меняются каждый год. GrantFinder помогает сориентироваться, но решение о подаче принимайте только по информации с официального сайта программы.

## Как внести вклад

Мы рады любой помощи: новой программе в каталоге, исправленной ссылке, правке в коде или документации.

1. Посмотрите открытые [issues](https://github.com/kadyrbaev555/GrantFinder/issues) или создайте новый по шаблону «Новая программа» или «Ошибка».
2. Создайте ветку от `main`, например `data/add-gks-2027` или `fix/empty-search`.
3. Сделайте коммиты в формате `тип: описание` (`feat:`, `fix:`, `docs:`, `data:`).
4. Откройте pull request и заполните шаблон. Перед слиянием нужен approve другого участника и зелёная проверка Secret Leak Check.

Подробные правила, требования к данным и чек-лист — в [CONTRIBUTING.md](CONTRIBUTING.md). Участвуя в проекте, вы соглашаетесь с [Кодексом поведения](CODE_OF_CONDUCT.md).

Зависимости npm, Go, Docker и GitHub Actions проверяет Dependabot: раз в неделю он открывает PR с обновлениями, а участники проверяют и сливают их как обычные изменения.
